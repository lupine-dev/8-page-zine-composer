# 8-Page Zine Composer

A browser-based tool for creating printable 8-page zines from individual page images. Upload your artwork or photos, and it assembles them into a properly laid-out spread, ready to print, cut, and fold.

## Usage

1. **Prepare** images for each page of your zine (photos, digital art, etc.). They can be files on your computer or photos from your phone.
2. **Load** each image using the "Browse" buttons below.
3. Click **"Make Zine!"** to assemble the layout.
4. Click **"Download Result"**, then print on standard printer paper.
5. **Cut and fold** — tutorials available [on YouTube](https://www.youtube.com/results?search_query=how+to+fold+an+8+page+zine).
6. You've got a zine! :3
